# Centroid CNC12 Mill Operator Manual

The CNC12 mill operator manual PDF (~57 MB) is **not committed** to this repo because of its
size. Download the current version directly from Centroid:

<https://www.centroidcnc.com/centroid_diy/downloads/operator_manuals/centroid-cnc12-mill-operator-manual.pdf>

A local copy at `docs/official/centroid-cnc12-mill-operator-manual.pdf` is gitignored (see
`.gitignore`). The other, smaller manuals in this directory (`centroid_plc_programming_manual.pdf`,
`centroid_plcexp1616_users_manual.pdf`, `teco-f510-instruction-manual.pdf`) are tracked directly.
