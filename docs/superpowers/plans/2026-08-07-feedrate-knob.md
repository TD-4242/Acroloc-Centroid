# Feedrate Preset Knob Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the four flat feedrate preset buttons (25/50/75/100%) on the retro VCP with a 2x2 analog-style dial built from those same four buttons, where the selected preset draws a needle.

**Architecture:** The dial's centre sits on the cell corner shared by all four cells, so each button owns one 90-degree sector and its needle falls entirely inside its own cell. That is what makes the design possible given a VCP button has only two image states driven by one PLC bit. A new `render_feedrate_knob_svg()` in the generator emits each cell's sector; the existing button XML, skin events and PLC outputs are reused untouched.

**Tech Stack:** Python 3 stdlib only (no pip, no pytest — `unittest` via `python3 tools/test_vcpgen.py`), SVG emitted as strings, Centroid CNC12 VCP skin XML.

**Spec:** `docs/superpowers/specs/2026-08-07-feedrate-knob-design.md`

## Geometry (from the spec)

Angles are degrees clockwise from straight up. Scale: `theta = 180 + 3 * value`.

| Quadrant | Grid cell | Dial centre (cell coords) | Sector | Preset | Needle angle | Values visible |
| --- | --- | --- | --- | --- | --- | --- |
| NW | row 13, col 4 | `(VB_W, VB_H)` = bottom-right | 270-360 | **50** | 330 | 30-60 |
| NE | row 13, col 5 | `(0, VB_H)` = bottom-left | 0-90 | **75** | 45 | 60-90 |
| SW | row 14, col 4 | `(VB_W, 0)` = top-right | 180-270 | **25** | 255 | 0-30 |
| SE | row 14, col 5 | `(0, 0)` = top-left | 90-180 | **100** | 120 | 90-100 |

The SE sector legitimately carries only values 90-100 plus the 60-degree dead gap between 100 and 0 — that is the knob's stop gap, not a bug.

        for q in self.QUADS:
            off = vcpgen.render_feedrate_knob_svg(q, False)
            on = vcpgen.render_feedrate_knob_svg(q, True)
            self.assertNotIn('fk-needle', off)
            self.assertIn('fk-needle', on)

    def test_needle_stays_inside_its_own_cell(self):
        # The whole design rests on this: each preset's needle must fall in
        # its own button's cell, because a VCP button can only swap its own
        # image. A needle crossing into a neighbour would be invisible.
        for q in self.QUADS:

            x, y = vcpgen._fk_pt(cx, cy, vcpgen.FKNOB_R_NEEDLE, th)
            self.assertTrue(0 <= x <= vcpgen.VB_W,
                            '%s needle x=%.1f outside cell' % (q, x))
            self.assertTrue(0 <= y <= vcpgen.VB_H,
                            '%s needle y=%.1f outside cell' % (q, y))

    def test_each_preset_owned_by_exactly_one_quadrant(self):
        presets = sorted(v[3] for v in vcpgen.FKNOB_QUADRANTS.values())
        self.assertEqual(presets, [25, 50, 75, 100])

```python
# --------------------------------------------- feedrate preset knob -------
# A 2x2 dial assembled from four ordinary 1x1 buttons. The dial centre sits on
# the cell corner all four share, so each cell shows a 90-degree sector and each
# preset's needle falls entirely inside its own cell -- the property that makes
# this work when a VCP button can only swap its own image (one PLC bit, two
# states). Scale: theta = FKNOB_THETA0 + FKNOB_SWEEP * value / 100, measured
# clockwise from straight up. Re-aim the dial by tuning THETA0/SWEEP alone.
FKNOB_THETA0 = 180.0    # value 0 sits at the bottom
FKNOB_SWEEP = 300.0     # 0 -> 100 sweeps 300 deg clockwise (60 deg stop gap)
FKNOB_R_FACE = 86.0     # tick ring outer radius, viewBox units
FKNOB_R_CAP = 44.0      # knob cap radius
FKNOB_R_NEEDLE = 74.0   # needle tip radius

# quadrant -> (centre x, centre y, sector start deg, preset value)
FKNOB_QUADRANTS = {
    'NW': (VB_W, VB_H, 270.0, 50),
    'NE': (0.0, VB_H, 0.0, 75),
    'SW': (VB_W, 0.0, 180.0, 25),
    'SE': (0.0, 0.0, 90.0, 100),
}


def _fk_pt(cx, cy, r, th):
    """Point at radius r and angle th (degrees clockwise from straight up)."""
    a = math.radians(th)
    return cx + r * math.sin(a), cy - r * math.cos(a)


def render_feedrate_knob_svg(quadrant, on):
    """One cell of the 2x2 feedrate preset dial.

    `on` adds the needle for this quadrant's preset. The bezel is drawn as a
    single 2x2 panel offset into this cell so the four cells join seamlessly
    rather than showing four separate button borders."""
    cx, cy, th_lo, preset = FKNOB_QUADRANTS[quadrant]
    th_hi = th_lo + 90.0
    # block-relative origin, so the bezel spans all four cells as one panel
    bx, by = cx - VB_W, cy - VB_H
    p = ['<svg xmlns="http://www.w3.org/2000/svg" width="%d" height="%d" '
         'viewBox="0 0 %d %d">' % (RENDER_W, RENDER_H, VB_W, VB_H),
         '<rect x="0" y="0" width="%d" height="%d" fill="#141210"/>'
         % (VB_W, VB_H),
         '<defs>' + _bezel_grad('bz', VB_W * 2, VB_H * 2) + '</defs>',
         '<rect x="%.1f" y="%.1f" width="%.1f" height="%.1f" rx="8" '
         'fill="url(#bz)" stroke="#100f0d" stroke-width="1.5"/>'
         % (bx + 3, by + 3, VB_W * 2 - 6, VB_H * 2 - 6)]
    for i in range(0, 101, 5):
        th = FKNOB_THETA0 + FKNOB_SWEEP * i / 100.0
        if not (th_lo <= th % 360.0 < th_hi):
            continue
        major = (i % 25 == 0 and i > 0)
        x1, y1 = _fk_pt(cx, cy, 78.0 if major else 81.0, th)
        x2, y2 = _fk_pt(cx, cy, FKNOB_R_FACE, th)
        p.append('<line x1="%.1f" y1="%.1f" x2="%.1f" y2="%.1f" stroke="%s" '
                 'stroke-width="%.1f"/>'
                 % (x1, y1, x2, y2,
                    '#e3ac5c' if major else '#6a645c', 2.0 if major else 1.0))
        if major:
            lx, ly = _fk_pt(cx, cy, 64.0, th)
            p.append(text_el(str(i), lx, ly + 4, 12, '#b0a898'))
    p.append('<circle cx="%.1f" cy="%.1f" r="%.1f" fill="#2a2724" '
             'stroke="#0c0b0a" stroke-width="2"/>' % (cx, cy, FKNOB_R_CAP))
    if on:
        th = FKNOB_THETA0 + FKNOB_SWEEP * preset / 100.0
        x1, y1 = _fk_pt(cx, cy, 10.0, th)
        x2, y2 = _fk_pt(cx, cy, FKNOB_R_NEEDLE, th)
        p.append('<line id="fk-needle" x1="%.1f" y1="%.1f" x2="%.1f" '
                 'y2="%.1f" stroke="#e3ac5c" stroke-width="4" '
                 'stroke-linecap="round"/>' % (x1, y1, x2, y2))
    p.append('</svg>\n')
    return ''.join(p)
```
