The directory is `git mv`d to preserve the two existing control references (`atc-flow.md`, `macros.md`); four new machine-fact files are added; `SKILL.md` is reframed around the whole machine and wired to route to all of them.

**Tech Stack:** Markdown skill files under `.claude/skills/` (Claude Code skill format: YAML frontmatter `name` + `description`, plus a router body). No code, no build, no automated tests — verification is by `grep`/file inspection.
