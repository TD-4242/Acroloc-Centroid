**Goal:** Add a signal-driven spindle-in-changer feed-hold interlock to
`Centroid-Acroloc-ALLIN1DC.src`, per
[the design](../specs/2026-07-09-spindle-changer-feedhold-design.md).

**Architecture:** One unified block in `MainStage` (replacing the stock stop block) drops the
spindle enable whenever Z is in the changer, and -- for program/MDI moves that enter with the
spindle still turning -- holds feed, waits for `ZeroSpeed_I` (INP12), then auto-resumes or faults
at a 5 s timeout. `ATCStage` gains a `ZeroSpeed_I` guard, and both `ATCStage` aborts get the same
full cleanup the finish rung already does.

**Tech Stack:** Centroid CNC12 / MPU11 PLC stage language. No build tooling in-repo; syntax/lint
via `./compile.sh` (MPUCOMP under wine).

- [ ] **Step 2: Delete the dead boot preset** (src:1292, inside `InitialStage`). Remove the line

  Verify the surrounding comma/line syntax of the `InitialStage` assignment list stays valid

- [ ] **Step 3: Replace the stock stop block** (src:2957-2964, "Make sure spindle stops before
  entering tool changer" through the dead `;IF StopSpinBeforeATC_T` / feedrate comment) with the
  unified interlock. It must remain in this location -- after the `SpinStart_M` seal-in coil in
  the "Turn spindle on/off" section -- so the per-scan `RST SpindleEnableOut_O` holds:

```
;=============================================================================
; Acroloc -- Spindle-in-changer feed-hold interlock (single unified rule)
;=============================================================================
; Danger zone = !ATC_Z_ClearedToolChanger_I  (INP26 FALSE = spindle in changer).
; ANY programmed or MDI move driving Z into the changer is held while the
; spindle is commanded off and reaches zero (confirmed by ZeroSpeed_I, INP12),
; then auto-resumed. The spindle is held OFF the whole time Z is in the zone and
; resumes at its commanded speed only after Z exits. Replaces the stock always-on
; stop block, KEEPING its unconditional zone spindle-kill. Resume is signal-
; driven: the instant ZeroSpeed_I confirms a stop; a 5 s timeout with the spindle
; still turning faults instead. Timer idiom: a bare timer is true WHEN EXPIRED.
; ActivateFeedHold_M is a self-clearing trigger (stock code RSTs it ~100 ms after
; set and SETs FeedHoldLED_O while set); DoCycleStart_SV clears FeedHoldLED_O to
; resume -- so no RST of ActivateFeedHold_M is needed here.

; -- 1. clear the once-per-entry latch whenever Z is clear of the changer
IF ATC_Z_ClearedToolChanger_I THEN RST ChangerHoldDone_M

; -- 2. keep the spindle commanded OFF the entire time Z is in the zone, ALL modes
IF !ATC_Z_ClearedToolChanger_I THEN
  RST SpindleEnableOut_O

; -- 3. clean bail-out if the program is stopped/canceled mid-hold
IF !(SV_PROGRAM_RUNNING || SV_MDI_MODE) THEN
  RST ChangerHoldActive_M, RST ChangerStopTimer_T, RST ChangerHoldDone_M

; -- 4. arm: program/MDI move into the zone with spindle NOT already stopped
IF (SV_PROGRAM_RUNNING || SV_MDI_MODE) && !ATC_Z_ClearedToolChanger_I
   && !ZeroSpeed_I && !ChangerHoldDone_M && !ChangerHoldActive_M THEN
  SET ChangerHoldActive_M,
  SET ActivateFeedHold_M,
  ChangerStopTimer_T = 5000,
  SET ChangerStopTimer_T

; -- 5. resume the instant zero is confirmed (signal-driven)
IF ChangerHoldActive_M && ZeroSpeed_I THEN
  SET ChangerHoldDone_M,
  RST ChangerHoldActive_M,
  RST ChangerStopTimer_T,
  SET DoCycleStart_SV

; -- 6. timeout with spindle still turning -> fault; motion stays held
IF ChangerHoldActive_M && ChangerStopTimer_T && !ZeroSpeed_I THEN
  FaultMsg_W = SPINDLE_FAULT_MSG_C,
  SET ShowFaultStage,
  SET OtherFault_M,
  SET ChangerHoldDone_M,
  RST ChangerHoldActive_M,
  RST ChangerStopTimer_T
```
